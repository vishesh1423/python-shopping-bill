# python-shopping-bill



# Project Overview

This is a beginner-level Python project that creates a simple shopping bill. The program takes the names and prices of 5 products from the user, stores them in lists, calculates the total bill, and identifies the highest- and lowest-priced products.

This project is designed to practice *lists, loops, user input, conditional statements, and built-in functions* in Python.

# Features

* Add names of 5 products
* Enter the price of each product
* Store product names and prices in separate lists
* Calculate the total bill
* Find the highest-priced product
* Find the lowest-priced product
* Display the product name and its price

# Technologies Used

*  *Python 3*
* Lists
* `for` loops
* `if-elif` conditions
* `input()`
* `int()`
* `sum()`

# How It Works

1. The program creates two empty lists:

   * `names` → stores product names
   * `prices` → stores product prices

2. A `for` loop runs 5 times to take product details from the user.

3. The product names and prices are added to their respective lists.

4. The program uses `sum()` to calculate the total bill.

5. It compares the prices to find:

   * The most expensive product
   * The least expensive product

6. Finally, it displays the results.
